# 🏭 Smart Factory Digital Twin & Predictive Maintenance Platform

## Overview

A complete Industry 4.0 engineering project that simulates a smart factory using Industrial IoT, FastAPI, MQTT, PostgreSQL, Machine Learning, Grafana, and Docker.

This project is being developed as an 8-week portfolio project following professional software engineering and engineering management practices.
